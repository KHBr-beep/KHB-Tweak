KHB TWEAK

Files:
- KHB-Tweak-Run.bat : launches ApplyTweaks.ps1 as Administrator
- ApplyTweaks.ps1   : applies KHB tweaks
- Restore.ps1       : restores the saved registry files and re-enables hibernation
- Check.ps1         : checks the KHB settings

Important:
- Review the scripts before distributing them publicly.
- The included backup is a per-run registry backup of selected HKCU keys only; it is not a complete Windows restore point.
- Widgets are intentionally skipped.
- Do not claim an FPS gain without benchmarking.
